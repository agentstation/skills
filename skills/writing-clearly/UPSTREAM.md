The source experiment compared a banned-word list, Orwell's rules, and an
ASD-STE100-inspired skill. Its results support using a coherent writing system
instead of treating individual words as the main problem.

AgentStation's skill is an original adaptation. It keeps a natural
conversational mode as the default, retains technical nuance, allows
contractions, and reserves stricter controlled-language rules for procedures,
safety text, and error messages. No source file or ASD-STE100 specification
text is vendored here.

ASD-STE100 is maintained by the ASD Simplified Technical English Maintenance
Group. The official specification remains the authority for conforming work:
https://www.asd-ste100.org/
