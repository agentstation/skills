      How plans are routed

      1. One owner plan per topic.
      2. Execution order below is the manifest. It lists each plan that is not terminal, one link per plan, in the order to execute them.
      3. Add a plan to the list in the change that creates the plan.
      4. Remove a plan from the list in the change that closes or archives it.
      5. Work that no plan owns goes in Work with no owner. A plan that takes a row names it and deletes the row.
